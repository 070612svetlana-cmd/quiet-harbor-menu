# Тихая гавань — онлайн-меню

Статический сайт с меню ресторана: приветственный блок, навигация по разделам, поиск по блюдам и избранное (сохраняется в `localStorage` браузера).

## Структура проекта

```
├── index.html      # главная страница
├── css/styles.css  # оформление
├── js/app.js       # логика: разделы, поиск, избранное, «наверх»
├── images/         # локальные фото блюд (по желанию)
└── README.md
```

## Как открыть локально

- Откройте `index.html` в браузере двойным щелчком, **или**
- Из корня проекта выполните:

```bash
npx --yes serve .
```

Затем перейдите по адресу, который покажет терминал (обычно `http://localhost:3000`).

## Возможности

- **Лендинг** — приветствие, кнопки «Смотреть меню» и «Что умеет сайт», кратко о режиме работы.
- **Разделы** — переключение категорий меню; активная кнопка подсвечивается.
- **Поиск** — фильтрация карточек по названию, описанию и цене; пустой запрос возвращает обычный вид одного раздела.
- **Избранное** — кнопка ♡/♥ на карточке; список хранится в браузере; счётчик рядом с полем поиска.
- **Наверх** — плавающая кнопка после прокрутки.
